    Sign in

    Use an Intune Administrator, Global Reader or Global Administrator account. Access is read-only — nothing is created in your tenant and no secret is stored.

    Use my Intune portal session Recommended · no consent needed

    Opens the Intune admin center in a browser window. Sign in exactly as you normally do — because the portal already has permission in every tenant, there is no consent prompt. Works when you hold only the Intune Administrator role. Your sign-in is remembered, so you only do this once. The captured session is temporary and cannot be renewed automatically.

    Advanced sign-in options

    The methods below request permissions for this tool directly, so the first use needs one-time approval by a Global Administrator, Privileged Role Administrator, Cloud Application Administrator or Application Administrator. An Intune Administrator cannot approve it.
